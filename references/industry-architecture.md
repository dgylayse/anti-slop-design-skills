# Industry website archetypes (v3)

The Site123 public website examples and support pages were consulted for **category inspiration only** (restaurants, events, portfolios, commerce, education and bookings), not as assets or templates to clone. No SITE123 customer layouts, trademarks, screenshots, data or media have been copied.

- https://tr.site123.com/web-site-%C3%B6rnekleri
- https://tr.site123.com/support/9927073-yeni-bir-sayfa-ekle

Each industry layout is expressed as: task → data fields → page hierarchy → responsive priority → functional states → trust/safety.

Never treat a static demo as evidence of deployed bookings, payment processing, appointments, accessibility testing or integrated search.
