# Anti-Slop Design Skills — v3.0

![Anti-Slop Design Skills](gallery/cover.png)

**82 design skills · 42 visual styles · 20 website architectures · 14 color palettes · 5 social-media directions · one Design Director.**

An original, visual-first library of design systems for AI coding agents, built for people who want more than the default AI landing page. Explore a historically informed **visual style**, choose a real **website type**, layer one **palette**, and produce accessible UI for actual tasks.

**[Browse the interactive visual gallery](gallery/index.html)** (open locally) · **[See every style at once](gallery/contact-sheet.jpg)** · [Türkçe rehber](README.tr.md)

Every skill has `SKILL.md` (agent instructions), `preview.png` (1280×800 browser screenshot), and `demo.html` (self-contained HTML/CSS/SVG source for that screenshot). All previews are original **illustrative studies**, *not functional launched websites*.

## What's inside

| Kind | Count | Purpose |
|---|---:|---|
| Historical / editorial visual styles | 42 | Personality, art direction, typography and composition |
| Industry website architectures | 20 | Real workflows: bookings, search, learning, inquiries and more |
| Compatible semantic color palettes | 14 | Six-color CSS contract; color without layout clones |
| Social-media art directions | 5 | Poster and campaign communication systems |
| Design Director | 1 | Matches category + style + palette and critiques output |

## Use in an agent

```bash
# From the root of this repository
python tools/install.py --list
python tools/install.py --skill design-director --skill restaurant-reservations --skill bistro-menu-illustrated --target /your-project/.agents/skills

# Claude Code / Gemini CLI local alternatives
python tools/install.py --skill legal-practice --skill swiss-editorial --target /your-project/.claude/skills
python tools/install.py --skill event-festival-schedule --skill cinema-ticket-retro --target /your-project/.gemini/skills
```

Or copy complete skill folders directly from this repository. `.agents/skills`, `.claude/skills` and `.gemini/skills` are examples; check the current documentation for your agent and its version. The YAML uses the Agent Skills-compatible keys `name`, `description`, `license`, `metadata`.

**Design prompt**

```text
Use design-director first. Build a responsive website using
[one industry layout] + [one visual style] + [optional one palette].
Identify the key user action, content hierarchy, mobile order and brand voice.
Follow the included token contract and keyboard/contrast/state guidance.
Avoid generic AI gradients, anonymous card grids and invented company facts.
Produce usable implementation code, not just a static mockup.
```

## Color-layer contract

Load style first, palette second. The palette may override only `--color-bg`, `--color-surface`, `--color-ink`, `--color-muted`, `--color-accent`, `--color-border`. Layout and style maintain their own spacing, geometry and typography. See [`references/token-contract.md`](references/token-contract.md) and [`examples/industry-recipes.md`](examples/industry-recipes.md).

## Build and quality checks

```bash
pip install -r requirements-dev.txt
python tools/validate_skills.py
python tools/build_gallery.py
python tools/build_contact_sheet.py
# Optional: regenerate previews; Chromium + Playwright required
python tools/render_previews.py
```

GitHub Actions checks YAML, semantic token contrast, image uniqueness/dimensions and gallery links. Runtime tests across all AI coding agents and all production app stacks have **not** been performed.
